      <section class="solution-section" aria-labelledby="uso"><h2 id="uso">Como usar a solução</h2><p class="solution-use">1. Copie o código do robô (código fonte) e cole em um novo fluxo Power Automate Desktop.
2.  Crie a variável de entrada login
3.   Crie a variável de entrada senha
4.  Crie a variável de entrada sistema</p></section>
      <section class="solution-section" aria-labelledby="observacoes"><h2 id="observacoes">Observações</h2><p class="solution-use">1. Na nova aba que será aberta, basta apertar Ctrl+A para selecionar todo código e Ctrl+C para copiar.
2. Login do usuário no sistema desejado. Em geral é o próprio masp do servidor, sem o dígito verificador
3. Senha do usuário no sistema desejado. Recomendamos incluir esta variável como confidencial.
4. Sistema para qual se deseja realizar o login. Valor padrão deverá ser, obrigatoriamente, uma das opções: sisap, siad ou siafi
0. Versão Power Automate: 2.39.00239.23332</p></section>
