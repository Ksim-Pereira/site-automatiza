      2. baixe a planilha modelo que se encontra no anexo.
      3. Crie a variável de entrada Caminho_excel com o caminho onde a planilha modelo foi salva.
      4. Crie a variável de entrada Caminho_pasta_automatiza onde serão salvos os prints de tela com os resultados das consultas.
